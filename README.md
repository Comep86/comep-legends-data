# COMEP Legends – Dati listone

Archivio pubblico tecnico per il sito COMEP Legends Fantacalcio.

- Nessun dato personale o credenziale.
- Aggiornamento automatico programmato ogni 15 minuti.
- Le quotazioni vengono pubblicate solo dopo controlli di validità sul numero di calciatori e sul formato dei dati.

Il sito COMEP mostra sempre data e fonte dell'ultimo aggiornamento; in caso di errore conserva l'ultimo JSON valido.
